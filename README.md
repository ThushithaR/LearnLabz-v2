Follow the steps below to run the project locally.

---

### 📦 Prerequisites

- Node.js (v16 or higher recommended)
- npm

---

### 🔐 Environment Variables

Create a `.env.local` file in the root directory and add the following variables:

```env
NEXT_PUBLIC_SUPABASE_URL=enter_link_here
NEXT_PUBLIC_SUPABASE_ANON_KEY=enter_key_here
SUPABASE_SERVICE_ROLE_KEY=enter_key_here
```
---

### 📥 Install Dependencies

```bash
npm install
```

---

### ▶️ Run the Development Server

```bash
npm run dev
```
Once the server is running the website will be avialable at `http://localhost:3000` in the web browser
